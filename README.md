Stroke Prediction Using Machine Learning

This mini-project focuses on predicting the risk of stroke based on key health factors. Using exploratory data analysis (EDA) and machine learning, we preprocess data, identify patterns, and build predictive models to assess stroke likelihood.

Goals
Analyze health data to identify stroke risk factors.
Apply EDA and statistical techniques for insights.
Develop and evaluate machine learning models for accurate predictions.
The project aims to support early detection and prevention of strokes using data-driven approaches.
